# Site

Branch: `site`
Worktree: sibling `showme-site`

Build the marketing page in `site/` to the visual language of https://wspx.vercel.app/.

- Background `#0b0c10`.
- Headlines in Redaction (OFL). Body in Schibsted Grotesk. Commands in ui-monospace.
- Hairline borders. One sky-blue accent. No drop shadows, no gradient text.
- Headline: "Show it once. Prove it on a clean machine. Any agent can run it."
- Install line: `python -m showme prove <skill> --set portal_url=... --set customer_id=...`
- Four beats on one diagram: watch, prove, approve, pack.
- Copy may describe only what the repo runs: two demonstrations induce parameters, a portal run writes the PDF, a renamed button halts, the folder is an Agent Skill.
- Use image files from `assets/` once they exist. Do not draw a fake verified hash or a fake star count.
- Leave `src/` and `tests/` alone.
