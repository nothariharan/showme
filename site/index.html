Watch. Prove. Approve. Pack.

Watch

You show the billing portal twice. A typed value or a server address that differs becomes a parameter. A click, a path, or a success check that differs is refused.

Prove

A clean run opens the portal and must write the tax PDF. The page says the download started, and the file is named with that customer id.

Approve

A renamed button stops the run. The message names the missing label and the controls on the page. Retarget points that one step at the new label.

Pack

The result is an Agent Skill folder. Bob, Claude Code, Cursor, and Codex read the same SKILL.md, trace, and player.
